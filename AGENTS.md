# Между книг

Static HTML/CSS/JavaScript website. All site files and local assets are in dist/. No dependency installation or build is needed.

Preview: python3 -m http.server 8000 --bind 0.0.0.0 --directory dist

Preserve existing Russian content, original photographs, artist portraits, responsive layout, keyboard controls, and reduced-motion support. Make only changes requested by the user. Do not invent missing artist biographies or exhibition facts.

After JavaScript edits run node --check on changed JS files. Check local asset paths. Use browser preview when available and report verification limits.

This GitHub copy is not automatically synchronized with the original chatgpt.site deployment. Do not claim that a commit publishes the website.
